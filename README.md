A modern, responsive freelance portfolio website for AI, Computer Vision, and Image Processing services.

- 📱 Fully Responsive Design
- 🎨 Modern Dark Theme with Gradients
- ⚡ Fast Loading & Optimized

- 🔍 SEO Optimized
- 📊 Portfolio Filtering
- ❓ FAQ Section

- 🏢 Client Logos Marquee

- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript
- Font Awesome Icons
- Google Fonts (Poppins)
